# Scrum-Proj

# Java Script Webapp (How to run)
Prerequisites: If you don't have nvm installed, install it first by following the instructions at: https://www.nvmnode.com/guide/download.html
1. **Clone the repository**
2. Change working directory to ./website
3. Run 
```bash
nvm install 22
nvm use 22
```
4. Run 
```bash
npm install 
```
in console

5. Start the server using
```bash
 npm run dev
```
 which will run the website on localhost:5173

# To run the project automatically
Open CMD in integration folder and run start.bat
